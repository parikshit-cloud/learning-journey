# ✅ What is Amazon S3 (Simple Storage Service)?

Amazon S3 is an object storage service provided by AWS that allows you to store and retrieve unlimited amounts of data, from anywhere on the web. It’s designed for scalability, durability, availability, and low-latency access to data such as images, videos, backups, documents, logs, and more.

---

## 📦 Key Concepts of Amazon S3

| Concept         | Description                                                                 |
|-----------------|-----------------------------------------------------------------------------|
| Buckets         | Containers that hold your data (objects). You must create a bucket before uploading data. |
| Objects         | The actual files/data you store in S3 (e.g., images, videos, text files, backups). |
| Keys            | Unique identifier for each object in a bucket (like a filename).           |
| Regions         | You choose a region to create your bucket to keep data close to users or apps. |
| Storage Classes | Different pricing/performance tiers for different data access needs.       |

---

## 🧱 Main Features of S3

| Feature             | Description                                                                 |
|---------------------|-----------------------------------------------------------------------------|
| Durability          | 99.999999999% (11 9’s) durability across multiple Availability Zones.       |
| Scalability         | Virtually unlimited storage; no upfront provisioning required.              |
| Availability        | High availability with multi-AZ redundancy.                                |
| Data Versioning     | Keep multiple versions of an object to protect against accidental deletion or overwrites. |
| Lifecycle Policies  | Automatically transition objects to cheaper storage classes or delete them. |
| Object Lock         | Prevent accidental deletion/modification with WORM (Write Once Read Many) protection. |
| Encryption          | Supports server-side and client-side encryption using AWS KMS or custom keys. |
| Access Control      | Use IAM policies, bucket policies, and ACLs to control access.              |
| Static Website Hosting | Host static websites (HTML, JS, CSS) directly from an S3 bucket.         |

---

## 🔐 S3 Storage Classes

| Class                  | Use Case                                       | Cost |
|------------------------|------------------------------------------------|------|
| S3 Standard            | Frequently accessed data                       | 💲💲💲 |
| S3 Intelligent-Tiering | Automatically moves data between access tiers | 💲💲  |
| S3 Standard-IA         | Infrequently accessed data, but needs quick access | 💲  |
| S3 One Zone-IA         | Cheaper, less durable (stored in one AZ)       | 💲  |
| S3 Glacier             | Archive storage (retrieval in minutes to hours)| 💲  |
| S3 Glacier Deep Archive| Lowest cost storage for archival data (retrieval in 12+ hours) | 💲 |

## 🧑‍💻 S3 Basic Commands (AWS CLI)

```bash
# Create a Bucket
aws s3 mb s3://my-bucket-name

# Upload a File
aws s3 cp myfile.txt s3://my-bucket-name/

# Download a File
aws s3 cp s3://my-bucket-name/myfile.txt .

# List Buckets
aws s3 ls

# Enable Versioning
aws s3api put-bucket-versioning --bucket my-bucket-name --versioning-configuration Status=Enabled
```

## 🛡️ Security and Access Control in S3

- **Bucket Policies**: Set access rules for the whole bucket (e.g., allowing public access to a website).  
- **IAM Policies**: Attach permissions to users/roles to access specific buckets or actions.  
- **ACLs (Access Control Lists)**: Legacy method to control object-level access.  
- **S3 Block Public Access**: Prevent accidental exposure of sensitive data to the public.

## 🌐 S3 Static Website Hosting Example

1. Enable static website hosting on your bucket.  
2. Upload `index.html` and `error.html`.  
3. Set public-read permissions.  
4. Access your website via the S3-hosted URL:  
   ```
   http://my-bucket-name.s3-website-us-east-1.amazonaws.com
   ```
